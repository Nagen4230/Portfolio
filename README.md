## 🚀 Key Interactive Features

1. **Embedded AI Career Assistant**: Floating drawer trained strictly on verified resume details, coursework, and projects with quick-prompt chips.
2. **Live Interactive Terminal**: Real-time line typing simulator showcasing Python problem-solving, Java class compilation, and Git build workflows.
3. **Animated Hero Canvas**: Lightweight 60fps HTML5 Canvas particle network with proximity-linked lines.
4. **Interactive Project Modals**: Deep-dive modals for full-stack web applications and video editing showcases.
5. **Metric-Driven Timeline**: Chronological milestones with gold callout metrics (UM degree studies, 4.00 CGPA, club presidencies, IIDEX/IYIA medals).

## 🛠️ Tech Stack & Architecture

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS (Obsidian, Crimson & Gold palette system)
- **Icons**: Lucide React
- **Typography**: Inter (Body & Headers) + Fira Code (Monospace & Terminal)
- **Deployment**: Vercel / GitHub Pages ready

## 💻 Local Development

### 1. Installation
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Production Build
```bash
npm run build
```
